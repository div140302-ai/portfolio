# Divesh Kissoon — Portfolio

A recruiter-friendly developer portfolio built with Next.js and designed for deployment on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Deploy to Vercel

1. Create a new GitHub repository (for example `portfolio`).
2. Push this project to that repository.
3. In Vercel, choose **Add New → Project** and import the repository.
4. Vercel should detect Next.js automatically. Click **Deploy**.

## Before publishing

- Check every GitHub/report URL in `app/page.tsx`.
- If you want a resume download button, place `Divesh_Kissoon_Resume.pdf` inside `/public` and add a link to `/Divesh_Kissoon_Resume.pdf`.
- Replace the `DK` hero monogram with a professional photo later if desired.
- Update the University of Mauritius graduation date once confirmed.
